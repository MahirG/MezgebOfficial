# Biloo Mezgeb production source

This branch contains the complete Biloo Mezgeb application at repository root for the existing `mezgeb-official` Vercel project.

- Canonical source: `MahirG/biloo_group/apps/mezgeb`
- Production branch: `biloo-mezgeb-production`
- Existing Supabase authentication, environment contracts, callback routes, and `mezgeb_*` tables remain unchanged.
- Existing production domains remain `gulit.shop` and `www.gulit.shop`.
- The branch passed formatting, lint, strict TypeScript, unit tests, Supabase email-template validation, production build, and desktop/mobile Playwright tests before deployment.
